# CQBar v0.1.0 — First public release

Release date: 2026-10-19

CQBar's first public Windows x64 release brings Codex quota status to the desktop.

## Highlights
- View five-hour and weekly quotas, usage, refresh status, and reset times.
- Includes a lightweight floating window and a taskbar toolbar on Windows 10 x64.
- The same installer provides Simplified Chinese and English interfaces.
